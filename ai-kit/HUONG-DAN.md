# Bộ tạo ảnh chân thật bằng Gemini (Nano Banana)

Cách làm mỗi ảnh: mở gemini.google.com → chọn "Tạo hình ảnh" → đính kèm các ảnh ghi ở mục "Đính kèm" → dán nguyên câu lệnh → tải ảnh kết quả về (bản đầy đủ, không chụp màn hình).
Nếu ảnh ra chưa ưng, gõ tiếp ngay bên dưới điều cần sửa (ví dụ "keep everything, make the floor darker rosewood").
Đặt tên file kết quả đúng như mục "Lưu thành" rồi gửi lại cho tôi.

Mẹo: làm ảnh số 1 trước và gửi tôi xem, ưng rồi hãy làm tiếp.

---

```

```
